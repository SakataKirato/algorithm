#アルゴリズム第一 アルゴリズム第一選択課題25-2A：整列

以下実行方法です。

①
```
gcc 2a-1.c
./a.out N # Nには所望の配列数を入力してください 例：./a.out 200000 とすると1~399999の内の奇数がキーとなった配列が確保され出力されます
```

②
```
gcc 2a-2.c
./a.out N # Nには所望の乗数を入力してください 例：./a.out 10　とすると、2^10 = 1024個分の1からの奇数がキーとなった配列が確保されソートされます
```

③
```
brew install gmp
brew reinstall gmp
make
./a.out N # Nには所望の乗数を入力してください　例：./a.out 10とすると、(2^10 - 1)/3 = 341となり、この値のchainlengthが出力されます
```
